 
Create **20 rank badge concepts**, but only show the user’s current badge and maybe the next badge. This keeps the UI simple.

Use this structure:

```text
Badge Name
Icon Concept
Visual Style
Meaning
```

## 4. Better Progression Order

I recommend arranging them like this:

```text
1. New Note
2. First Pin
3. Sticky Starter
4. Note Keeper
5. Task Buddy
6. Pin Helper
7. Board Scout
8. Task Ranger
9. Checklist Pro
10. Quick Finisher
11. Board Captain
12. Task Guardian
13. Workflow Hero
14. Done Dealer
15. Pin Commander
16. Task Champion
17. Board Master
18. Quest Master
19. Workflow Legend
20. TaskPin Elite
```

This progression feels natural because the badge starts simple and becomes more prestigious.

## 5. Visual Direction Per Badge Tier

### Beginner Tier

```text
New Note
First Pin
Sticky Starter
Note Keeper
```

Visual style:

```text
Yellow, soft orange, simple sticky-note icons
```

These should look cute, simple, and welcoming.

---

### Active Contributor Tier

```text
Task Buddy
Pin Helper
Board Scout
Task Ranger
Checklist Pro
Quick Finisher
```

Visual style:

```text
Green, orange, blue, checklist, board, small shield icons
```

These should look like the user is becoming reliable.

---

### Leader Tier

```text
Board Captain
Task Guardian
Workflow Hero
Done Dealer
Pin Commander
```

Visual style:

```text
Blue, purple, gold, shield, cape, star, command badge
```

These should feel stronger but still friendly.

---

### Elite Tier

```text
Task Champion
Board Master
Quest Master
Workflow Legend
TaskPin Elite
```

Visual style:

```text
Gold, platinum, crown, trophy, premium badge emblem
```

These should feel rare and rewarding.
